Zeno's primitives animate with [`tw-animate-css`](https://github.com/Wombosvideo/tw-animate-css).
Adding the theme installs it as a dev dependency, and your stylesheet imports it (see
[Installation](/docs/core-framework/building-ui/installation)):

```css title="src/app/globals.css"
@import "tw-animate-css";
```

The shadcn primitives, such as the accordion, dialog, and dropdown menu, use its utility classes
for their enter and exit transitions.

More motion documentation is coming soon.
