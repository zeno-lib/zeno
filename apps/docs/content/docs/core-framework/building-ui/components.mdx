Zeno's primitives are the [shadcn](https://ui.shadcn.com) components, built on
[Base UI](https://base-ui.com) and styled with Tailwind CSS. Go to the [shadcn components](https://ui.shadcn.com/docs/components)
page to browse the full catalog and add any of them with the CLI:

```npm
pnpm dlx shadcn@latest add button dialog
```

Once added, you can import them like so:

```tsx
import { Button } from "@{yourWorkspace}/ui/components/button"
import { Dialog, DialogContent, DialogTrigger } from "@{yourWorkspace}/ui/components/dialog"
```

## Anatomy

- Composition via Base UI's `render` prop: pass another element to swap the underlying tag (e.g. render a `Button` as a Next.js `Link`)

```tsx
import Link from "next/link"
import { Button } from "@/components/ui/button"

<Button render={<Link href="/recover">Recover</Link>} variant="link" />
```
