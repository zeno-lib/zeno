Zeno's primitives are the [shadcn](https://ui.shadcn.com) components, built on
[Base UI](https://base-ui.com) and styled with Tailwind CSS. Browse the full catalog on the
[shadcn components](https://ui.shadcn.com/docs/components) page, and add any of them with the CLI:

```npm
pnpm dlx shadcn@latest add button dialog
```

Then import them from the shared `ui` package:

```tsx
import { Button } from "@{yourWorkspace}/ui/components/button"
import { Dialog, DialogContent, DialogTrigger } from "@{yourWorkspace}/ui/components/dialog"
```

## Anatomy

Base UI components compose through the `render` prop. Pass another element to swap the
underlying tag, for example to render a `Button` as a Next.js `Link`:

```tsx
import Link from "next/link"
import { Button } from "@/components/ui/button"

<Button render={<Link href="/recover">Recover</Link>} variant="link" />
```
