Zeno uses [Vitest](https://vitest.dev) for fast, modern unit testing with native TypeScript support.

## Setup

Add `@zeno-lib/test` to your package and use the shared config:

```typescript
// vitest.config.ts
export { default } from "@zeno-lib/test/configs/default"
```

For React packages, use `@zeno-lib/test/configs/react`:

```typescript
// vitest.config.ts
import { defineReactConfig } from "@zeno-lib/test/configs/react"

export default defineReactConfig()
```

## Writing Tests

```typescript
import { describe, expect, test } from "@zeno-lib/test"

describe("Calculator", () => {
  test("adds two numbers", () => {
    expect(1 + 2).toBe(3)
  })

  test("handles edge cases", () => {
    expect(0 + 0).toBe(0)
    expect(-1 + 1).toBe(0)
  })
})
```

## Commands

```bash
# Run tests once
pnpm test

# Watch mode
pnpm test:watch

# Run for specific package
pnpm turbo run test --filter @zeno-lib/example
```

## Testing React Components

Use `@zeno-lib/test/testing-library` and `@zeno-lib/test/user-event` (included in `@zeno-lib/test`):

```typescript
import { describe, expect, test } from "@zeno-lib/test"
import { render, screen } from "@zeno-lib/test/testing-library"
import { Button } from "@zeno-lib/ui/button"

describe("Button", () => {
  test("renders with text", () => {
    render(<Button>Click me</Button>)
    expect(screen.getByRole("button")).toHaveTextContent("Click me")
  })
})
```

## Mocking

```typescript
import { vi, describe, expect, test } from "@zeno-lib/test"

const mockFetch = vi.fn()

describe("API", () => {
  test("fetches data", async () => {
    mockFetch.mockResolvedValue({ data: "test" })
    const result = await mockFetch()
    expect(result.data).toBe("test")
  })
})
```

## Environment Variables

Tests run with `NODE_ENV=test`. The shared config loads `.env.test` automatically — create a `.env.test` file for test-specific variables.

## Best Practices

- Write assertions inside `test()` blocks
- Use `async/await` instead of done callbacks
- Don't commit `.only` or `.skip`
- Keep tests focused and independent
- Use descriptive test names
