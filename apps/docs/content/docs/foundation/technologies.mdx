## Core

- **[TypeScript 7](https://www.typescriptlang.org)**: JavaScript with syntax for types
- **[React 19](https://react.dev)**: the UI library Zeno's components are written in
- **[Next.js 16](https://nextjs.org)**: the React framework Zeno apps run on, with the App Router

## Build & dev tools

- **[Turborepo](https://turbo.build/repo)**: runs the monorepo's tasks in dependency order and caches their outputs
- **[Turbopack](https://turbo.build/pack)**: the bundler Next.js 16 uses by default
- **[Ultracite](https://ultracite.ai)**: JavaScript/TypeScript linting and formatting, as a Biome preset

## Styling

- **[Tailwind CSS 4](https://tailwindcss.com)**: utility-first CSS framework
- **[shadcn/ui](https://ui.shadcn.com)**: component primitives you copy into your app, and the registry Zeno ships its UI items through

## Database & backend

- **[Supabase](https://supabase.com)**: Postgres database and auth, run locally with the Supabase CLI
- **[Drizzle](https://orm.drizzle.team)**: TypeScript ORM that `@zeno-lib/db` and `@zeno-lib/schema` build on

## Testing

- **[Vitest](https://vitest.dev)**: unit test runner, with shared presets in `@zeno-lib/test`
- **[Playwright](https://playwright.dev)**: end-to-end browser testing, with the shared preset in `@zeno-lib/e2e`
