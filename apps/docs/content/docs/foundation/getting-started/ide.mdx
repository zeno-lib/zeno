Zeno requires [Cursor](https://cursor.com), an AI code editor built on [VS Code](https://code.visualstudio.com). The project relies on Cursor hooks, which plain VS Code doesn't run.

The repo includes the extension recommendations, editor settings, formatter config and Cursor hook, so you only need to open the project in Cursor and install the recommended extensions.

## Recommended extensions

`.vscode/extensions.json` lists the recommended extensions, so Cursor prompts you to install them when you open the project. You can also install them by hand:

| Extension | Purpose |
|-----------|---------|
| [Biome](https://marketplace.visualstudio.com/items?itemName=biomejs.biome) | Linting & formatting |
| [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) | Tailwind autocomplete |
| [Tailwind Fold](https://marketplace.visualstudio.com/items?itemName=stivo.tailwind-fold) | Collapse long Tailwind class lists |
| [MDX](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) | MDX language support |
| [Pretty TypeScript Errors](https://marketplace.visualstudio.com/items?itemName=yoavbls.pretty-ts-errors) | Readable TypeScript errors |
| [Vitest](https://marketplace.visualstudio.com/items?itemName=vitest.explorer) | Test runner integration |
| [Playwright Test](https://marketplace.visualstudio.com/items?itemName=ms-playwright.playwright) | E2E test runner |

## Settings

The repo ships a `.vscode/settings.json`. The main settings are:

- **Biome** is the default formatter for all supported file types (TypeScript, JavaScript, JSON, HTML, CSS, MDX, etc.)
- **Format on save** and **format on paste** are enabled
- **Code actions on save** fix lint issues and organize imports
- **CSS files** open in the `tailwindcss` language mode, so Tailwind IntelliSense works in them
- **TypeScript SDK** points to the workspace `node_modules` version

Because the file is committed, every clone gets these settings.

## Cursor configuration

The `.cursor/` directory contains project-specific AI configuration:

- **Rules**: AI-specific coding standards loaded automatically for matching files
- **Hooks**: auto-format and lint after every AI-generated file edit

See [AI setup](/docs/foundation/getting-started/ai-setup) for details.
