## Requirements

### Package manager

Zeno is a [pnpm](https://pnpm.io) workspace. Install pnpm globally:

```npm
npm install -g pnpm
```

### Node.js

Zeno requires Node.js 24. Install it from the [Node.js website](https://nodejs.org/en/download/).


## Quick start

Clone the Zeno repository:

```bash
git clone https://github.com/zeno-lib/zeno.git
cd zeno
```

Install dependencies:

```npm
pnpm install
```

Start the development servers:

```bash
pnpm dev
```

## Verify installation

Run the full CI pipeline to check that everything works:

```bash
pnpm ci
```

This runs:
1. Linting with Ultracite
2. TypeScript type checking
3. Building all packages
4. Unit tests with Vitest
5. E2E tests with Playwright
